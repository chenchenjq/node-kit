# 02 — 领域类型、规范化与纯规则

Status: ready-for-agent

实现 spec §2～§3、§6、§9 的浏览器安全类型与纯函数：稳定/草稿身份、标签规范化、CNY 十进制校验、问题码与 `Result`、组合键、容量提前计算、内置/宿主预设复制、图片引用、管理/消费者/历史 DTO 的类型隔离。组合键必须是版本化规范 JSON，默认组合为 `v1:[]`，客户端不能构造受信任正式 ID。

验收：覆盖 Unicode/空白/大小写判重、单位不归并、金额 null/零/边界/超精度、1～5 维组合及超限提前失败、默认组合、同一标签不同历史身份、消费者类型无法访问供应价。
