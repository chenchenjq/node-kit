# 03 — 差异预览与选择图纯核心

Status: ready-for-agent

实现完整目标结构的校验与保留/新增/移除/待恢复差异计算，处理 draftKey、改名/替换、排序和默认/多规格模式；实现由宿主消费者投影构建选择图、部分选择下一步、完整选择精确解析、图片回退和 complete/partial/unknown 实际价格范围。不得把停用/归档、缺货、不存在组合和未知混成一个状态。
