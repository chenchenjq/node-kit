# sms-kit Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the private TypeScript package, stable domain/port contracts, security primitives, PostgreSQL schema, optional `pg` adapter, and deterministic test foundation used by every later sms-kit capability.

**Architecture:** Keep domain code independent of Alibaba Cloud, Better Auth, Next.js, and PostgreSQL. Aggregate focused repository ports behind `SmsStore`; implement them with PostgreSQL under a separate export and prove compatibility through reusable contract tests.

**Tech Stack:** Node.js 20+, npm workspaces, TypeScript 7.0.2, ESM/NodeNext, Vitest 5.0.0, Zod 4.6.4, libphonenumber-js 1.13.13, pg 8.23.0, Testcontainers 12.1.0, PostgreSQL 17.

**Spec:** `doc/prd/001-sms-kit.md`; persistent model: `doc/数据库设计.md`

## Global Constraints

- Package name is exactly `sms-kit`; directory is exactly `packages/sms-kit/`; `package.json` must set `"private": true`.
- Runtime floor is Node.js 20; source is TypeScript strict; output is ESM with `.d.ts` declarations.
- Package is server-only. Browser bundles must never receive Secret resolution, plaintext phone data, OTPs, or decrypted render parameters.
- Core must not import Alibaba Cloud SDK, Better Auth, Next.js, `pg`, or Testcontainers.
- Core storage contracts are ORM-independent; PostgreSQL and `pg` are optional implementation exports.
- Provider configuration and resources are system-global; operational records are scoped by a required trusted `TenantId`. Single-tenant hosts inject one fixed default ID.
- All timestamps are UTC instants; persisted values use PostgreSQL `timestamptz`; API serialization is ISO 8601.
- Never store plaintext Secret, OTP, phone number, or asynchronous template values.
- Do not run `npm publish`; do not create a registry `.npmrc`; do not add the untracked root `AGENTS.md` to commits.
- Run only `sms-kit` checks because no other package exists yet.

const deliveryTransitions: Record<DeliveryStatus, readonly DeliveryStatus[]> = {

export function validateTemplateVariables(
  declared: readonly string[],
  values: Readonly<Record<string, string>>,

  const missing = declared.filter((name) => !(name in values));

type CipherEnvelope = { v: 1; iv: string; tag: string; data: string };

async function sealBytes(key: Buffer, plaintext: Buffer): Promise<string> {
  const iv = randomBytes(12);
  const cipher = createCipheriv("aes-256-gcm", key, iv);
  cipher.setAAD(Buffer.from("sms-kit:cipher-envelope:v1"));
  const data = Buffer.concat([cipher.update(plaintext), cipher.final()]);
  const envelope: CipherEnvelope = {
    v: 1,
    iv: iv.toString("base64url"),
    tag: cipher.getAuthTag().toString("base64url"),
    data: data.toString("base64url"),
  };
  return Buffer.from(JSON.stringify(envelope)).toString("base64url");
}
