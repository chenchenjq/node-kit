# area-kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可在独立宿主安装、离线查询和服务端校验的私有 area-kit，包括真实五级导入、版本存储、React 选择/管理与四份使用文档。

**Architecture:** 单个 ESM 包，根类型与 server/postgres/client/react 分入口。宿主注入存储和授权，固定来源通过显式脚本准备、校验、分批导入并按需激活；React 按父级加载，业务提交重新校验版本化完整路径。

**Tech Stack:** Node.js、TypeScript strict、React/Next.js、Drizzle node-postgres、PostgreSQL、csv-parse、Vitest、Testing Library、Testcontainers、Playwright；候选精确版本见下表，只有执行通过的组合才写为已支持。

**Spec:** `doc/prd/003-area-kit.md`，配套 `doc/数据库设计.md` 的 area-kit 段落。执行者须读取两者及本计划；本计划不是已实现能力或测试通过报告。

## Global Constraints

- 所有功能位于 `packages/area-kit/`；新建包时同步更新 `PACKAGES.md`。
- 包设置 `private: true`；服务端入口拒绝进入浏览器构建。
- 各宿主独立保存数据，同一宿主内共享区域基准；业务读取策略、认证和管理权限由宿主提供。
- 区域代码、名称、层级和归属不作为普通字典，不接入 dict-kit，不提供源节点任意增删改。
- 默认表名 `area_dataset`、`area_region`；每一对表代表一个区域库，最多一个活动版本，不新增租户列或覆盖继承。
- 固定 commit：`c49d495b40ac73eb1a66f6eeae5f8fd10696f035`；dataAsOf=`2023-06-30`，sourcePublishedAt=`2023-09-11`，不宣称最新数据。
- 代码及关联代码字段保留原字符串；不通过 trim、补零或截短修复；source_name 保留原值。
- targetLevel 为 1～5，默认 3，按源 level 判断，不按 UI 列数。
- 列表、下级和搜索默认每页 50 条，最多 200 条；批量编码最多 200 条；搜索关键词最多 100 字符。
- 小树深度最多 3，最大返回 level=3，节点上限 5,000；恰好 5,000 允许，超过则报错。
- 提前终止默认不接受，分组默认只导航；例外须来自可信宿主，不能由 HTTP 输入放宽。
- 新提交缺省 active-only；历史读取允许旧 ready 版本和业务停用节点，不自动重写地址。
- 正式导入全部批次与进度事务使用持 session lock 的同一物理连接；源异常阻止 ready/激活。
- 首版默认不启用跨请求缓存，不强制 Redis；业务提交校验重新查询数据库。
- 全量数据与 `.tgz` 分离；不进入浏览器构建；初始化后的业务运行不依赖 GitHub。
- 不包含国外区域、GIS、经纬度、邮编、地址智能解析、编码映射、配送范围、自动爬虫、独立认证/RBAC 或复杂版本合并。
- 不执行生产迁移/导入、推送、发布或远程设置修改；不提交连接串、凭据或密钥。
- 保留原有未提交修改；只检查本包和真实测试宿主，不无条件运行全部 workspaces 检查。

const allowed = new Set(['localhost','127.0.0.1','::1',process.env.AREA_TEST_DB_IP].filter(Boolean));
function permit(host) {
  const name = String(host ?? 'localhost').replace(/^\[|\]$/g,'').toLowerCase();

  appendFileSync(process.env.AREA_OFFLINE_LOG,JSON.stringify({pid:process.pid,host:name})+'\n');

const connect = net.Socket.prototype.connect;
net.Socket.prototype.connect = function (...args) {
  const normalized = Array.isArray(args[0]) ? args[0] : args;
  const first = normalized[0];
  if (typeof first === 'object' && first !== null) {
    if (!first.path) permit(first.host);
  } else if (!(typeof first === 'string' && first.startsWith('/'))) {
    permit(typeof normalized[1] === 'string' ? normalized[1] : 'localhost');
  }
  return Reflect.apply(connect,this,args);
};
for (const target of [dns,dns.promises,dns.Resolver.prototype,dns.promises.Resolver.prototype]) {

}
