# synthetic/：合成样例生成器

这里的用例由 `generate.ts` 按固定种子（默认 `20240918`）从 `test/fixtures.ts` 的区域树随机拼装：
随机丢弃开头若干级行政区、随机拼接路名/门牌/楼栋/单元/房号、随机附姓名电话与备注噪声。

**它不是标注集，也不能用来宣称准确率**：地名组合是人造的，没有「真实正确地址」这一说。
它唯一的用处是在足够多的样本上压解析路径，验证与本包承诺绑定的**结构性不变量**：

1. 门牌、楼栋、单元、房号等要素不会凭空消失（要么在 `detailedAddress`，要么在 `residualText`/收件人字段里）；
2. 输出的区划代码必须都来自宿主快照（不得臆造出快照里没有的层级）；
3. 标为 `explicit` 的层级必须能在原文中回指到区间；
4. 标为 `inferred` 的层级必须带 `LEVELS_INFERRED` 警告，且必须 `requiresReview`。

准确率类指标一律只在 `../annotated/` 上计算。
