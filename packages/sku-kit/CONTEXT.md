# SKU 配置上下文

本上下文描述宿主商品下可销售规格组合的稳定身份。商品、成交、发布与履约仍由宿主拥有。

## Language

**作用域（Scope）**:
可信服务端提供的商品命名空间；作用域键与 SPU ID 共同标识一个宿主商品。即使单租户部署也必须提供非空作用域键。
_Avoid_: 租户 ID、商城 ID（作用域不承诺具体业务含义）

**SPU**:
由宿主拥有、在一个作用域内唯一的商品身份；本上下文只引用，不拥有商品本身。
_Avoid_: 商品记录、SKU 父表

**SKU**:
一个 SPU 下稳定的可销售规格组合身份。SKU 不等同于库存记录，规格显示调整、排序或其他 SKU 的移除都不改变其身份。
_Avoid_: 库存、库存行、数组行

**SKU 编码（SKU Code）**:
SKU 首次持久化时获得并终身保留的人类可读编码，由该 SPU 注册时的编码与两位序号组成。编码不是 SKU 身份，不随宿主之后的显示或编码变化而改写。
_Avoid_: SKU ID、当前 SPU 编码的实时派生值

**注册 SPU 编码（Registered SPU Code）**:
一个 SPU 首次持久化 SKU 配置时冻结的宿主编码快照，供该 SPU 后续分配 SKU 编码；它在作用域内永久唯一，不能转交给另一个 SPU。
_Avoid_: 当前 SPU 编码

**销售规格维度（Sales Specification Dimension）**:
用于区分 SKU 的一类选择，例如颜色或尺码。描述参数与物流属性不是销售规格维度。
_Avoid_: 商品属性、参数、模板字段

**销售规格值（Sales Specification Value）**:
销售规格维度下具有稳定身份的一个选择，例如红色或 M；显示文字不是其身份。
_Avoid_: 标签、数组下标

**有效规格（Active Specification）**:
当前 SKU 配置可以选择的销售规格维度或值。历史 SKU 保留已经归档的规格关系，不按当前有效规格重新解释。
_Avoid_: 所有历史规格

**改名（Rename）**:
明确表示含义不变的规格显示文字修正，沿用原维度或值身份。
_Avoid_: 替换

**替换（Replace）**:
明确表示含义变化的规格变更，创建新的维度或值身份，并重新计算受影响组合。
_Avoid_: 改名

**组合（Combination）**:
一个 SPU 下由每个当前销售规格维度各选择一个规格值所形成的 SKU 身份依据。
_Avoid_: 规格名称拼接、笛卡尔积行号

**配置草稿（Configuration Draft）**:
尚未持久化的规格与组合编辑状态，没有正式 SKU 身份或编码，也不占用编号容量。
_Avoid_: 默认 SKU、已初始化商品

**默认 SKU（Default SKU）**:
没有自定义销售规格时使用的空组合 SKU。“默认规格”只是界面标签，不是虚构的规格维度或规格值。
_Avoid_: 默认规格维度、默认规格值

**快捷预设（Preset）**:
可复制到当前 SPU 的销售规格建议；复制后形成当前 SPU 自己的维度和值身份，与预设不再动态关联。
_Avoid_: 规格模板绑定、共享规格身份

**SKU 主图引用（SKU Image Reference）**:
宿主图片适配器能够解析的稳定文件引用；它不是临时访问 URL，也不表示文件由 SKU 独占。
_Avoid_: 签名 URL、文件所有权

## 价格

**建议零售价（Suggested Retail Price）**:
SKU 上可空的 CNY 参考金额，用于给宿主提供定价建议，不是消费者实际支付价格。
_Avoid_: 售价、成交价

**供应价（Supply Price）**:
SKU 上可空的 CNY 成本侧参考金额，只能出现在获准的管理视图中。
_Avoid_: 消费者价格、建议零售价

**实际售价（Sale Price）**:
宿主价格规则为消费者投影的 CNY 金额，不由 `sku-kit` 从建议零售价或供应价推导。
_Avoid_: 建议零售价、供应价

**完整价格范围（Complete Price Range）**:
所有可见候选 SKU 都有宿主实际售价时形成的范围。
_Avoid_: 建议价范围

**部分价格范围（Partial Price Range）**:
只有部分可见候选 SKU 有宿主实际售价时形成的已知范围，必须明确标记为不完整。
_Avoid_: 完整价格范围、缺失价格为零

**库存记录（Inventory Record）**:
与 SKU 关联的数量事实，由一次部署明确选择的库存权威拥有；它不是 SKU 身份的一部分。
_Avoid_: SKU、可购买承诺

**库存权威（Inventory Authority）**:
一个作用域内唯一解释和修改库存事实的能力来源，可以是本地可读写、外部可读写或外部只读。未知库存是独立结果，不等同于零库存。
_Avoid_: 库存副本、SKU 写权威

**已知库存（Known Inventory）**:
库存权威明确返回的非负整数数量及其版本。
_Avoid_: 推测库存

**未知库存（Unknown Inventory）**:
库存权威没有数据或暂时无法给出数量的结果；它既不表示零库存，也不表示有货。
_Avoid_: 零库存、读取成功

**可购买判定（Purchasability Decision）**:
宿主结合发布状态、实际成交价、库存及业务规则得出的交易判断；SKU 的启用状态或库存快照本身都不是可购买承诺。
_Avoid_: SKU 启用、库存大于零

**选择图（Selection Graph）**:
从宿主允许展示的 SKU 投影得到的规格选择关系，描述部分选择还能到达哪些候选及其原因状态。只有完整选择精确命中一个 SKU 才形成选中结果。
_Avoid_: 全部 SKU 列表、自动最低价选择

**管理视图（Management View）**:
供已授权管理者配置当前结构、价格、图片、状态与库存连接信息的投影，可以包含历史身份。
_Avoid_: 消费者视图

**消费者视图（Consumer View）**:
宿主按发布、价格、库存和权限规则投影后允许消费者看到的规格与 SKU 信息，其类型不包含供应价。
_Avoid_: 管理 DTO 删字段

**历史读取视图（Historical Read View）**:
用于解释已归档 SKU 及其原规格关系的投影；它不是订单或成交快照。
_Avoid_: 历史订单

## SKU 状态

**停用（Disabled）**:
SKU 的默认持久化状态；保留当前配置，但不作为启用的候选项。
_Avoid_: 草稿、归档

**启用（Enabled）**:
SKU 可以进入宿主展示与销售判断的状态；启用本身不代表可购买。
_Avoid_: 在售、有货

**归档（Archived）**:
SKU 不再用于新选择、但永久保留原身份、编码和历史规格关系的状态。归档 SKU 只能通过明确操作以原身份恢复。
_Avoid_: 删除、释放编号

## 配置变化

**保留组合（Retained Combination）**:
修改前后由同一组稳定维度和值身份构成的组合；它沿用原 SKU 身份、编码和已有配置。
_Avoid_: 同名组合

**新增组合（Added Combination）**:
目标配置中没有对应历史 SKU 身份的组合；首次持久化时获得新的 SKU 身份和编码。
_Avoid_: 重建组合

**移除组合（Removed Combination）**:
当前配置不再包含、但历史身份及关系仍被保留的组合；已经持久化的 SKU 转为归档，而不是物理删除。
_Avoid_: 删除组合、释放组合

**待恢复组合（Restorable Combination）**:
目标配置重新包含、且已有归档 SKU 身份的组合；只有请求明确指定原 SKU 身份时才能恢复，不能自动新建或自动恢复。
_Avoid_: 新增组合、同名组合

**SKU 写权威（SKU Write Authority）**:
一次部署中唯一可以持久化 SKU 配置的存储实现，可以是 `sku-kit` 的默认存储，也可以是遵守同一契约的宿主存储。
_Avoid_: 双写、副本同步
